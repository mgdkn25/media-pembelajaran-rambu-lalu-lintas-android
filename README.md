# 🚦 Media Pembelajaran Interaktif Rambu-Rambu Lalu Lintas Berbasis Android

Media pembelajaran interaktif berbasis Android yang dirancang untuk membantu
siswa sekolah dasar mengenal dan memahami rambu-rambu lalu lintas melalui
materi visual, navigasi interaktif, latihan soal, dan evaluasi.

## 📱 Project Overview

Project ini merupakan hasil pengembangan media pembelajaran interaktif
sebagai bagian dari tugas akhir/skripsi.

Aplikasi dirancang dengan pendekatan multimedia pembelajaran agar materi
rambu-rambu lalu lintas dapat disampaikan dengan cara yang lebih menarik,
visual, dan mudah dipahami oleh siswa sekolah dasar.

## 🎯 Tujuan

- Membantu siswa mengenal berbagai rambu-rambu lalu lintas.
- Memberikan informasi mengenai arti dan fungsi rambu.
- Menyediakan media pembelajaran yang interaktif dan menarik.
- Memberikan latihan dan evaluasi untuk mengukur pemahaman siswa.

## 👦 Target Pengguna

**Siswa Sekolah Dasar**

## ✨ Fitur Utama

### 📚 Materi Pembelajaran

Aplikasi menyediakan beberapa pilihan materi pembelajaran mengenai
rambu-rambu lalu lintas.

### 📝 Latihan Soal

Siswa dapat mengerjakan latihan soal untuk membantu memahami materi
yang telah dipelajari.

### 📋 Soal Evaluasi

Tersedia soal evaluasi untuk mengukur pemahaman siswa mengenai
rambu-rambu lalu lintas.

### 🚦 Pembelajaran Berbasis Visual

Materi menggunakan gambar dan ilustrasi agar informasi mengenai
rambu-rambu lebih mudah dipahami.

## 🛠️ Tools yang Digunakan

- Microsoft PowerPoint
- iSpring
- Website2APK Builder

## 🔄 Development Process

### 1. Analisis Kebutuhan

Mengidentifikasi kebutuhan media pembelajaran mengenai rambu-rambu
lalu lintas untuk siswa sekolah dasar.

### 2. Perancangan Materi

Menentukan materi, struktur pembelajaran, navigasi, latihan,
dan evaluasi.

### 3. Perancangan Visual

Membuat tampilan pembelajaran dengan menggunakan elemen visual,
ilustrasi, warna, dan navigasi yang sesuai untuk siswa sekolah dasar.

### 4. Pengembangan Media Interaktif

Materi pembelajaran dan interaksi dikembangkan menggunakan
Microsoft PowerPoint dan iSpring.

### 5. Packaging Android

Media pembelajaran kemudian dikemas menjadi aplikasi Android
menggunakan Website2APK Builder.

### 6. Pengujian

Aplikasi diuji untuk memastikan navigasi, materi, latihan,
dan evaluasi dapat berjalan sesuai dengan rancangan.
